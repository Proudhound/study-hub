# Verhaltensregeln

Wir fördern eine sachliche, respektvolle und offene Zusammenarbeit. Beiträge sind unabhängig von Erfahrungsstand und Hintergrund willkommen.

- Kritik bitte an Ideen und Code richten, nicht an Personen.
- Belästigung, Drohungen, persönliche Angriffe oder das Offenlegen privater Informationen werden nicht toleriert.
- In Issues und Pull Requests keine sensiblen Studiendaten, privaten Screenshots oder personenbezogenen Informationen veröffentlichen.
- Maintainer dürfen Beiträge moderieren, schließen oder entfernen, die diesen Grundsätzen widersprechen.

Bei Sicherheitsproblemen möglichst GitHubs private Schwachstellenmeldung nutzen. Bei Konflikten zuerst um eine private Klärung mit den Maintainers bitten; öffentliche Diskussionen sollen keine privaten Kontaktinformationen offenlegen.
