# Studieren und Lernen

Private zentrale Ablage für Studium, Weiterbildungen und Themen, die aktiv gelernt werden sollen.

## Ziel

Das Repository soll langfristig Lernmaterial, Lernpläne, Prüfungsvorbereitung und KI-gestützte Lernwerkzeuge zusammenführen. Geplant ist, einzelne Fächer bzw. Module getrennt zu führen und aus den jeweiligen Modulmaterialien gezielt Lernhilfen zu erzeugen.

## Status

Die endgültige Repository-Struktur wird noch gemeinsam festgelegt. Deshalb ist dieser Stand bewusst minimal und legt **noch keine verbindliche Ordnerarchitektur** für Grundstudium, Weiterbildung, Master oder einzelne Module fest.

Aktuelle Planungsunterlagen liegen unter `planning/`.

## Geplantes Prinzip

Ein späterer Modulordner soll als abgeschlossener Lernkontext funktionieren können:

`Quellen / Unterlagen -> Aufbereitung -> Erklären / Diskutieren -> Active Recall / Quiz -> Wiederholung -> Prüfungsvorbereitung`

KI-Werkzeuge sollen dabei auf das Material des jeweiligen Moduls zugreifen können, ohne dass alle Lerninhalte ungeordnet im Repository vermischt werden.

## Nächster Schritt

Gemeinsam festlegen:

- endgültige Top-Level-Struktur
- Benennung für Studium / Weiterbildung / Master / freie Lernthemen
- Standardstruktur eines Modulordners
- Umgang mit PDFs, Skripten, Notizen, Lernkarten und generierten Lernartefakten
- Rolle von OpenMAIC / AI Teaching Agents
- mögliche Lern-Webanwendungen innerhalb des Repositories
